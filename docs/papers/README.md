# Foundational Research Papers (arXiv)

Per the [arXiv API Terms of Use](https://info.arxiv.org/help/api/index.html), full-text PDF preprints are not redistributed in the public Git repository. You can view them directly on arXiv.org or download them into this folder (`docs/papers/`) with the commands below:

1. **OpenJev-RLCD: A Working RLCD Implementation** (*Z. Gao & P. Wang, Sept. 2026*)
   - Abstract: https://arxiv.org/abs/2609.38850
   - PDF: https://arxiv.org/pdf/2609.38850.pdf
2. **AnyJev Technical Report** (*Nokia Applied Research, Sept. 2026*)
   - Abstract: https://arxiv.org/abs/2610.00831
   - PDF: https://arxiv.org/pdf/2610.00831.pdf
3. **StartLux-Decision: AutoThink Decision Models with RLCD²** (*StartLux & HKU, Oct. 2026*)
   - Abstract: https://arxiv.org/abs/2610.17309
   - PDF: https://arxiv.org/pdf/2610.17309.pdf

## Download Locally

```bash
curl -L https://arxiv.org/pdf/2609.38850.pdf -o docs/papers/2609.38850_OpenJev_RLCD.pdf
curl -L https://arxiv.org/pdf/2610.00831.pdf -o docs/papers/2610.00831_AnyJev.pdf
curl -L https://arxiv.org/pdf/2610.17309.pdf -o docs/papers/2610.17309_StartLux_Decision.pdf
```
