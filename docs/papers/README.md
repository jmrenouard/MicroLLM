You can inspect every paper via the interactive API (`GET /v1/papers`), the CLI (`microllm papers`), the comprehensive synthesis in [`docs/LITERATURE_REVIEW.md`](../LITERATURE_REVIEW.md), or download the PDFs directly from arXiv.org below.

## 1. Three Core Architectural Pillars of MicroLLM

1. **OpenJev-RLCD: A Working RLCD Implementation** (*Zhimin Gao & Pichao Wang, Sept. 2026*)
   - Abstract: https://arxiv.org/abs/2609.38850
   - PDF: https://arxiv.org/pdf/2609.38850.pdf
   - **MicroLLM Mapping**: Implemented in [`src/microllm/rlcd.py`](../../src/microllm/rlcd.py) (`Proposition 1` group-mean variance identity, shifted Brier reward `r(u, y*)`, Stage 1 pathwise calibration + Stage 2 REINFORCE LOO-KL).
2. **AnyJev Technical Report** (*Jiamu Zhang, Tianze Yang, Yucheng Shi, Evan Chen, Zixiang Nie, Kelly Wan — Nokia Applied Research, Sept. 2026*)
   - Abstract: https://arxiv.org/abs/2610.00831
   - PDF: https://arxiv.org/pdf/2610.00831.pdf
   - **MicroLLM Mapping**: Implemented in [`src/microllm/backends/prefill_llm.py`](../../src/microllm/backends/prefill_llm.py) (Gear 2 `L0` circular rotation readout with exact slot-bias cancellation, binary-reflected Van der Corput early stopping, and `OnlinePriorTracker` label-prior debiasing).
3. **StartLux-Decision: AutoThink Decision Models with Reinforcement Learning for Calibrated Deliberative Decisions** (*Xialie Zhuang, Zunhai Su, Jia Pan, Ngai Wong, Guanhua Chen, Chuan-Wei Kuo — StartLux & HKU, Oct. 2026*)
   - Abstract: https://arxiv.org/abs/2610.17309
   - PDF: https://arxiv.org/pdf/2610.17309.pdf
   - **MicroLLM Mapping**: Implemented in [`src/microllm/backends/cascade.py`](../../src/microllm/backends/cascade.py) (`DualGearCascadeBackend` combining Gear 1 Instant encoder with Gear 2 AutoThink escalation), [`src/microllm/rlcd.py`](../../src/microllm/rlcd.py) (`RLCD^2` `Beta(8,2)` importance weights), and [`src/microllm/benchmarks.py`](../../src/microllm/benchmarks.py) (`DecisionPivot` contrastive pair benchmark).
